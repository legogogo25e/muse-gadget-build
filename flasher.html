Flash controls

If sync fails, drop one step and retry.

Auto-flash only triggers while a device is connected and the serial port is not busy flashing or monitoring; if the monitor is open it is stopped first. Rollback uses the previous firmware bytes kept in this page's memory — it does not need the network and only works while this page stays open.

Post-flash checks

Serial output received
Any data from the device after the monitor opens.
Booted successfully
The boot log shows ESP-IDF / app_init markers and is not immediately followed by a reset.
No crash / no reboot loop
No Guru Meditation, panic or abort seen; an abnormally high reset count is flagged as a reboot loop.

The checks read the live log from the serial monitor on the right. Results stay in this browser; use "Copy check report" to send them together with the log.

Local firmware (optional)

If GitHub Pages cannot be reached, pick local .bin files here and enter a flash address for each (hex, e.g. 0x20000). Once any local file is added, flashing uses only the local set — it is never mixed with the cloud firmware.
